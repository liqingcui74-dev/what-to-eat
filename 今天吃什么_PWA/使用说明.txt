今天吃什么？PWA 使用说明

文件：
- index.html：主页面
- manifest.webmanifest：PWA 安装配置
- service-worker.js：离线缓存
- icons/：桌面图标

重要：
PWA 必须通过 HTTPS（或电脑 localhost）访问，不能仅双击本地 HTML 后安装。

最简单发布方式：
1. 把整个文件夹上传到 GitHub 仓库。
2. 用 GitHub Pages / Cloudflare Pages / Netlify / Vercel 任意一种免费静态托管。
3. 用手机浏览器打开 HTTPS 地址。
4. 浏览器菜单选择“添加到主屏幕/安装应用”。
5. 安装后桌面会出现“吃什么”图标，打开时是独立全屏窗口。
